# Portfolio — Ioritz Laduche

Portfolio personnel d’Ioritz Laduche, étudiant ingénieur en informatique à ISA NUM. Présentation, CV imprimable et projets Mintza et MainsTendues, dans un style néobrutaliste.

## Hébergement GitHub Pages

Dans le dépôt GitHub : Settings → Pages → Build and deployment.
Choisir « Deploy from a branch », branche « main », dossier « / (root) », puis Save.

Adresse attendue après publication : https://ioritzladuche.github.io/Portfolio/

## Modifier le site

- `index.html` : présentation, projets et liens.
- `style.css` : mise en page et couleurs.
- `app.js` : présentations interactives et filtres.
- `cv.html` : CV imprimable et export PDF depuis le navigateur.
- `assets/` : logos des projets.

Après modification, enregistrer les fichiers, créer un commit et le pousser vers main. GitHub Pages publiera la mise à jour automatiquement.

Le CV reste à compléter avec les coordonnées, les dates et les expériences. Les polices proviennent de Google Fonts, avec des polices système en secours.
